# HRMS Lite – Full Stack (React + FastAPI)

HRMS Lite is a lightweight Human Resource Management System built with a **React (Vite) frontend** and a **FastAPI backend**.  
It allows an admin to manage employees and track attendance records.

---

## 🚀 Tech Stack
- **Frontend**: React (Vite), React Router DOM, Axios
- **Backend**: FastAPI, Python
- **Database**: PostgreSQL
- **Deployment**: Netlify (Frontend), Railway (Backend)

---

## 📋 Prerequisites
Before running this project locally, ensure you have:
- Python 3.9+
- pip (Python package manager)
  
## Installations
- Clone project in your pc from git.
- Create a virtual Environment and activate it.
- pip install -r requirements.txt
- Chage origins link for local host in main.py CORS.
- Create a .env file and create db link and enter your db credentials as required in environment file.
